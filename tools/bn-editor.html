說明
文字／CTA 位置都照 PSD 量測值擺放（深藍圓角＝CTA）。 格紋底＝未選主題時的視覺佔位（KV／講師視覺本階段不處理，選了主題會換成底圖）。

總覽：不用捲動看到所有勾選的版位縮圖，點一下放大檢視。
畫布：可縮放/平移，仔細檢查或編輯用。

LOGO 位置：依主題而定——有的主題是固定橫排（蝦大／蝦皮直播＋分隔線＋ 最多 3 個廠商 LOGO 位，由素材包自動帶入，等距等比排列），有的主題改成圍繞 人物照片的圓圈徽章，數量/位置各版位自己決定。橫式版位齊左、直式／方形版位置中。
蝦皮／直播 LOGO 有橘、白兩版，依主題底色自動挑（工單配色表指定）。

人物框：所有主題都有人物框，預設就放第一張圖素（img/圖素版/ 的 1200×700 去背 PNG）。點右欄的縮圖換一張，或改上傳自己的照片蓋掉； 換圖素／換照片時，位置縮放角度都會一起歸零。
兩種來源共用同一個圖素定位框（照插畫實際大小標的框，比公版人物框更貼合， 下緣超出版位是設計上的出血）：圖素貼的是「插畫實際看得到的範圍」（去背 PNG 四周的 透明邊不算）；自己上傳的照片沒有已知的透明邊界可貼合，整張 contain 進同一個框。
新增圖素＝把 png 丟進 img/圖素版/，再在 packs/bn/photo-assets.js 加一行。

雙人上傳照片：按「人物照片」分頁的「+ 新增人物2」，兩邊都上傳自己的照片 後會自動把圖素定位框拆成左右兩塊（重疊約 8%）——人物1在左、人物2在右， 預設人物1的圖層在上面。圖素模式不會拆，插畫本身已經是完整構圖。

位置調整（兩層）：套進來的時候整張固定在定位框內（不會被裁到）。
① 整體＝右欄那個小預覽框，一次套用到所有版位。
② 單一版位＝切到畫布模式直接點該版位的人物照片。
兩邊的操作完全一樣：拖曳移動、拉四角等比縮放（固定對角，跟 PS 自由變形一樣）、拉上方圓把手旋轉（按住 Shift 吸附 15°）， 倍率 20%～500%。右欄另有 ±／⟲ 按鈕可以微調與重設。
（不用滾輪縮放——右欄捲動時太容易誤觸，已改成只靠選取框與按鈕。）
單獨調過的版位不會再被①的整體調整覆蓋；要讓它跟回整體，按選取框下方的 ⟲ 還原，或按右欄黃色的「套用至所有版位」再選「覆蓋手動調整的版位」。

兩層都不受定位框限制——可以放大到超出框、也可以拖到框外，只受版位邊界裁切。

小預覽框裡的虛線＝定位框，虛線外那圈是框外空間，方便看照片溢出多少； 虛線與畫布上的選取框都只是編輯輔助，不會印進下載的圖。

字數為軟性提示：超過仍可輸入，只是提醒版面會被撐開。
